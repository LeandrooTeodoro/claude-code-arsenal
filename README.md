## Como usar

Copie a pasta da skill para `~/.claude/skills/` e o agente para `~/.claude/agents/`. Para plugins completos, o ideal é instalar pelo marketplace oficial de cada projeto. Exemplo:

```bash
/plugin marketplace add affaan-m/ECC
```
